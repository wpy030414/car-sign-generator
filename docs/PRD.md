# PRD — 机动车号牌生成器

## 产品目标

- 提供一个**严格参照各国标准文件**的机动车号牌生成器：用户选择国家/地区与号牌类型，逐字段编辑内容，实时看到按标准物理尺寸（mm）、字符比例、配色渲染的号牌，并一键导出 4K 高清 PNG。
- 把「标准」变成「可追溯的数据」：每个版式的尺寸、字符 ink 尺寸、笔画、间距、颜色都来自标准条款，并在 UI 中标注出处（citation）。

## 用户与使用场景

- **目标用户**：字体/平面设计研究者、号牌标准学习者、需要做号牌视觉素材的设计师（合法用途）、对各国号牌文化感兴趣的爱好者。
- **典型场景**：
  1. 选择「中国 · 小型汽车号牌」，输入 `京 A 00001`，预览蓝底白字号牌，导出 4K PNG 用于设计稿。
  2. 切换到「欧盟 · 德国式」，输入地区代码 + 注册号，看到蓝带 12 星 + FE-Schrift 字符，对比不同成员国配色。
  3. 选择「日本 · 自家用中板」，输入地名/分类番号/假名/一连番号，理解四色版式（白绿黄黑）对应的车辆用途。
  4. 通过 URL 分享一个特定号牌配置给他人。

## 核心问题

- **旧版不直观**：只有「预设下拉 + 文本框 + 整串正则校验」，用户看不到字段拆解，无法逐项编辑，非法输入只有一句「非法的牌号」。
- **旧版难维护**：靠 CSS `transform: scale()` 拉伸字符模拟号牌字体，字形比例失真；尺寸/颜色散落在多个 CSS 文件；新能源分隔点引用外链图床 PNG（随时失效，且导出时污染画布）。
- **旧版无法导出**：没有保存图片能力。
- **旧版单一国家**：仅中国，且未严格对照标准的 mm 尺寸/字符尺寸/颜色落地。

## 功能及其意义

| 功能                     | 解决什么              | 为什么需要                                                         |
| ------------------------ | --------------------- | ------------------------------------------------------------------ |
| 四国号牌标准数据         | 旧版仅中国、不严谨    | 覆盖中/欧/美/日，每类版式带 citation 可追溯                        |
| 编辑器（国家/类型/字段） | 旧版整串输入不直观    | 逐字段编辑 + 实时校验 + 字符集约束，所见即所得                     |
| mm 精确 SVG 渲染         | 旧版 CSS 拉伸字形失真 | 1 user unit = 1mm，字符按标准 ink 尺寸精确拟合                     |
| 各国专用字体（开源替代） | 官方字体受版权保护    | OFL/Apache 字体 + 子集化，合法内嵌且体积小                         |
| 4K PNG 导出              | 旧版无导出            | 字体 base64 内联 → Canvas 栅格化，矢量精度高清输出                 |
| URL 持久化               | 配置无法分享          | 任意号牌 = 一条可分享链接                                          |
| 安装孔开关               | 导出图样需干净底图    | 关闭后可用于二次设计                                               |
| 预览缩放与全屏           | 小号牌细节看不清      | 左下角 25%–300% 缩放、右下角全屏，均为本地观看状态，不写入分享链接 |

## 功能之间的关系

- 用户在**编辑器**选择国家/类型 → 从**标准注册表**取出对应 `PlateType` 数据 → **布局引擎**按 mm 计算字符单元格与 ink 拟合 transform → **PlateSvg** 渲染矢量号牌（含各国装饰组件）→ 预览实时刷新。
- 点击导出 → 克隆预览 SVG → **fonts 模块**把用到字体转 base64 注入 → **export 模块**序列化、栅格化到 4K Canvas、下载 PNG。
- 每次编辑写入 **Zustand store**，并把整份配置（JSON → base64url）同步到 URL 的 `config` 参数。

## 范围与非目标

- **范围内**：
  - 中国 GA 36-2018 表1 的 20 类版式（大型汽车前/后、挂车、新能源小型/大型、小型汽车、教练、警用、使馆、领馆、港/澳入出境、普通/轻便/教练/警用摩托、使馆/领馆摩托、低速车、临时行驶）。
  - 欧盟单行号牌（德/法/意/荷/通用式）+ 蓝带 12 星 + 国别代码。
  - 美国 6×12in 通用物理标准（白底黑字基线 + 几种常见配色）。
  - 日本中板/大板/小板四色版式。
  - 编辑器、实时校验、4K 导出、URL 分享。
- **范围外**：
  - 官方受版权字体的像素级复刻。
  - 各国州别/地区特殊图案底（美国各州图形、日本彩边摩托小板等）。
  - 双行欧盟号牌；拖拉机号牌（按 NY 345.1 执行）；带底纹图案的纸质临时号牌。
  - 后端服务、用户系统、批量生成、号牌真伪校验。
  - 任何违法用途（伪造/变造号牌）。
